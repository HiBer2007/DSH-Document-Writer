# 机器味清单（machine-flavor）

> 翻译腔、公文腔、翻译机腔的识别与改法。
> 与 `human-rubric.md` 轴 3 配套；评审时逐类扫，命中 ≥2 类判"机器味偏高"。

---

## 1. 翻译腔句式

| 模式 | 例子 | 改法 |
| --- | --- | --- |
| 在…的背景下 | 在数字化转型的背景下 | 2025 年公司上线新系统后 |
| 对于…而言 | 对于大学生而言 | 对我这种大三学生 |
| 作为…的一部分 | 作为项目的一部分 | 这个项目里 |
| 对…进行… | 对数据进行分析 | 拆开数据看 |
| 进行…的工作 | 进行了调研的工作 | 跑了三家店 |
| 被…所… | 被市场所认可 | 市场认了 |
| 使得 | 使得效率提升 | 效率上来了 / 效率提高 |
| 不仅…而且… | 不仅提高效率，而且降低成本 | 效率高了，成本也降了 |
| 一方面…另一方面… | 一方面…另一方面… | 直接说两件事，不加壳 |
| 就…而言 | 就就业而言 | 就业这块 |

**判断**：把句子翻回英文再翻回中文，如果更顺，说明是翻译腔。

---

## 2. 名词化堆叠

| 模式 | 例子 | 改法 |
| --- | --- | --- |
| 抽象名词 | 可操作性、有效性、必要性、重要性 | 能不能做、有没有用、要不要 |
| 动词变名词 | 进行了深入的分析 | 拆开看了 |
| 价值判断 | 具有一定的参考价值 | 可以参考 |
| 程度副词 + 名词 | 在很大程度上 | 多半 / 大多数时候 |

**判断**：一句话里 ≥3 个"性/度/化"结尾的词，基本就是机器味。

---

## 3. 连接词机械

高危词：首先、其次、再次、最后、综上所述、由此可见、与此同时、此外、因此、然而、总之、值得注意的是、需要指出的是。

**改法**：

- 能用语义衔接就不用连接词（上一句的结果就是下一句的原因）；
- 必须用时换成人话："所以""不过""还有一个""说白了"；
- 一段最多一个连接词。

---

## 4. 句式单一

| 表现 | 改法 |
| --- | --- |
| 每句 20–30 字、主谓宾齐全 | 插一个 8 字短句 |
| 没有插入语 | 加"说实话""按我的理解"（学术语体可少量） |
| 没有转折 | 加"不过""但有个问题" |
| 没有反问/设问 | 学术写作慎用，可改成"这就带来一个问题：" |

**判断**：连续 5 句长度差 < 5 字，判句式单一。

---

## 5. 无细节

| 表现 | 改法 |
| --- | --- |
| 只有结论没有过程 | 补一个具体观察（时间、地点、数字、动作） |
| 全是"显著提升""有效改善" | 换成"从 62% 到 78%" |
| 没有失败/异常 | 补一句"第二批数据偏高，怀疑是温度波动" |

**注意**：细节必须真实；不知道就不写，不许编。

---

## 6. 语义空转

| 表现 | 改法 |
| --- | --- |
| 一句话说两遍 | 删一句 |
| 形容词堆叠（"重要而关键的核心"） | 留一个 |
| "具有重要意义" | 说清楚对谁有什么用 |
| 同义反复（"提高了提升效果"） | 删 |

**判断**：删掉半句后意思不变 → 那半句是空的。

---

## 7. 标点与节奏

| 表现 | 改法 |
| --- | --- |
| 40 字不断句 | 拆成两句 |
| 分号并列三项以上 | 改列表或拆句 |
| 破折号连用 | 一段最多一个 |
| 全角逗号连缀 | 该句号就句号 |

---

## 8. 判定与修复顺序

1. 先改翻译腔（最刺眼）。
2. 再拆名词化（最长句）。
3. 然后调节奏（短句、断句）。
4. 最后补细节（没有就跳过，不许编）。
5. 改完重读一遍：如果更像"人写的报告"而不是"翻译的论文"，就算过。

---

## 9. 与"去 AI 味"的区别

| | AI 味 | 机器味 |
| --- | --- | --- |
| 来源 | 生成模型的写作习惯 | 翻译/模板/公文习惯 |
| 典型 | 三段式、空洞升华、模糊归因 | 翻译腔、名词化、连接词机械 |
| 改法 | 删膨胀、破结构、给具体判断 | 还原成中文语序、动词化、断句 |
| 共同点 | 都让文章"正确但不像人" | 同左 |

**只做同义词替换 = 两味都去不掉，还会新增机器味。**

## 10. 鱼八股（AI 新八股）

> “鱼八股”是网友对 DeepSeek 系模型常见文风的称呼（“鱼”指 DeepSeek 的鲸鱼形象），
> 本质是《光明日报》所说的“AI 新八股”的一个具体流派。
> 来源：[破解“AI新八股”困局](https://news.gmw.cn/2026-05/17/content_38768705.htm)。

### 10.1 三个特征

1. **结构固化**：机械套用“总—分—总”“现状—问题—对策”、工作总结三段式、评论四段论；
   每段先总结后展开，段首必带序号词。
2. **正确的空话**：高频大词堆叠——赋能、抓手、闭环、底层逻辑、顶层设计、认知维度、
   颗粒度、组合拳、新范式、新篇章、新画卷、时代浪潮、行稳致远、答卷、底色、成色、亮色。
   删掉这些词，句子信息不变。
3. **内容同质化**：同类主题的观点、逻辑、措辞高度相似，千文一面；排比三连、金句结尾、
   情绪拔高、口号式号召。

### 10.2 为什么同义词替换没用

- 把“赋能”换成“帮助”，模板结构和空逻辑还在，读起来仍然是“正确但空”。
- 逐词替换会破坏指代、术语和句间衔接，造成明显的上下文割裂；评审判定机器味更重。
- 词表只能用来**定位**可疑处，不能作为**改写方法**。

### 10.3 改法（按顺序）

1. **删结构**：去掉“总—分—总”的总结句、序号词、每段三点式；按真实论证关系重排。
2. **删大词**：把“赋能/抓手/闭环”换成具体对象、动作、数字；删后意思不变就删。
3. **补事实**：时间、地点、人物、数字、失败/异常；不知道就不写，不许编。
4. **变节奏**：长句拆短，短句接长；一段最多一个连接词。
5. **降情绪**：删排比三连、金句结尾、口号式号召；结尾落到具体判断或下一步。
6. **读前后句**：改完读前后各一句，确认指代、术语、逻辑没断；断了就回滚重写。

### 10.4 判定

- 命中 ≥2 类（结构固化 / 正确的空话 / 内容同质化）→ AI 味偏高，必须 revise。
- 只做词表替换 → 直接 reject：那不是改写。

## 11. 搭配错位（形容词与名词的语义范畴不匹配）

### 11.1 是什么

形容词的语义特征（价格、温度、尺寸、重量等）在名词的范畴里不成立，上下文也没有建立
相应的隐喻框架。典型：

> 更值钱的追问有两个。

“追问”是抽象的言语行为，没有市场价格；“值钱”的 [+可标价/可交易] 特征落不到
[+抽象] 的“追问”上。正常说法是：

- 更有价值的追问
- 更值得追问的问题
- 更关键的追问
- 更根本的追问

### 11.2 快速检验

1. **还原字面义**：把形容词换回字面意思——“能卖钱的追问”成立吗？不成立。
2. **查名词特征**：追问有“价格”吗？没有；有“价值/重要性/根本性”吗？有。
3. **看上下文**：有没有建立交易、代价、稀缺的框架？没有就是搭配错位。

### 11.3 改法

- 回到常用搭配：有价值、值得、重要、关键、根本、紧迫。
- 或者把隐喻写实：只有真的在谈钱/代价时，才写“这个问题值钱，因为答案能直接影响……”。
- 不要换成另一个花哨形容词（“更金贵的追问”）——那是同义词替换，不是修复。

### 11.4 判定

- 命中一处明确搭配错位 → 记 issue（quote + fix），`aiFlavor` 至少上调。
- 多处或反复出现 → `aiFlavor` 偏高，必须 revise。
- 价格隐喻不是一律禁止：“廉价的同情”“昂贵的代价”是熟语或有上下文支撑；
  错的是把经济词当“高级/重要”的万能形容词，硬贴抽象名词。

### 11.5 与鱼八股的区别

| | 鱼八股 | 搭配错位 |
| --- | --- | --- |
| 问题 | 大词空转、结构固化 | 词义范畴不匹配 |
| 例 | “赋能抓手闭环” | “值钱的追问” |
| 改法 | 删大词、破结构、补事实 | 换回常用搭配或把隐喻写实 |

两者可以同时命中；都按“先定位、再按句重写”处理，不许用同义词替换糊过去。
